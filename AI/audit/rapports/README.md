# Rapports d'audit

Un fichier par axe, ecrit par la conversation qui conduit l'audit :
`axe-<N>-<slug>.md`. Format impose par `AI/audit/README.md`.

Ces fichiers sont des **constats**, pas des correctifs. Ce qui est retenu part ensuite
vers une conversation de correction, avec un perimetre ferme.

Vide a ce jour.
