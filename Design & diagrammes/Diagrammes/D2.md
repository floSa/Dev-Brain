## Définition

Outil en ligne de commande (`d2`) qui lit un fichier `.d2` et produit un diagramme. Le langage est volontairement court : `x -> y -> z` suffit à dessiner trois boîtes reliées ; les blocs imbriqués décrivent des groupes, `shape:` choisit la forme (cylindre pour une base, personne, hexagone…), `style.` règle le trait. `d2 --watch in.d2 out.svg` ouvre le résultat dans le navigateur et le recharge à chaque modification. Les sorties : SVG, PNG, GIF, PDF et PPTX. D2 est aussi une **bibliothèque Go**, avec un analyseur qui rapporte plusieurs erreurs à la fois, un formateur automatique, des thèmes officiels et des extensions pour VS Code, Vim et Obsidian.

Le placement est confié à un **moteur de mise en page** au choix : Dagro (par défaut, port Go de Dagre), elk-go (port de ELK, adapté aux graphes orientés avec ports), et TALA, moteur propre à D2 conçu pour les diagrammes d'architecture logicielle, à activer par `--layout=tala`. La licence de TALA n'a pas été relevée ici : le dépôt la dit incluse et optionnelle, à vérifier avant de s'en servir. D2 ne contacte pas internet après l'installation, sauf pour vérifier les mises à jour sur GitHub d'après sa FAQ. Version 0.9.0 du 2026-09-07 (le numéro majeur n'est pas encore 1), licence MPL-2.0 lue dans le dépôt, dépôt poussé le 2026-10-02.

## Prendre si / Écarter si

| Prendre si | Écarter si |
|---|---|
| Un diagramme versionné en texte, avec un rendu plus travaillé que celui de [[Mermaid]] : thèmes, style croquis, placement contrôlable | Le diagramme doit s'afficher tel quel dans GitHub, GitLab ou Obsidian sans étape de rendu : [[Mermaid]] y est natif |
| Un diagramme d'architecture dont les éléments ont des formes et des niveaux emboîtés | Un **modèle** d'architecture dont les vues se calculent : [[LikeC4]] |
| Un outil qu'on lance en CI pour produire des images de la documentation, et qu'on appelle depuis Go | Le catalogue le plus large de types de diagrammes UML : [[PlantUML]] |
| Un binaire sans runtime, sans serveur | Un éditeur graphique où l'on place chaque forme à la main : [[draw.io]] |

## Mise en œuvre

- Installation — `curl -fsSL https://d2lang.com/install.sh | sh -s --` (avec `--dry-run` pour voir les commandes), un gestionnaire de paquets du système, ou `go install github.com/d2lang/d2@latest` (sans la page de manuel)
- Point d'entrée — `d2 --watch in.d2 out.svg` ; `d2 layout` liste les moteurs de placement
- Prérequis — aucun pour le binaire
- Exécution — sur le poste ou en CI ; un bac à sable en ligne existe (play.d2lang.com) mais n'est pas nécessaire
- Coût — gratuit sous licence MPL-2.0

## Écosystème

### Alternatives

- [[Mermaid]] — Diagram-as-code open-source (MIT, JavaScript) : décrire flowcharts, séquence, ERD, Gantt… en texte type markdown, versionnable et rendu nativement par GitHub et Obsidian. — rendu par GitHub et Obsidian ; D2 produit des images plus soignées mais demande une étape de rendu.
- [[PlantUML]] — Outil Java (licences au choix : GPL, LGPL, Apache, EPL ou MIT) qui dessine des diagrammes UML et plus de vingt types — séquence, classes, activité, états, Gantt, carte mentale, JSON, YAML — à partir d'une description textuelle, en ligne de commande, en bibliothèque ou compilé pour le navigateur — mais GitHub ne les rend pas nativement, il faut une extension de navigateur ou un rendu en amont. — le langage historique des diagrammes UML ; D2 a une syntaxe plus courte.
- [[LikeC4]] — Outil en ligne de commande (MIT, TypeScript) : décrire une architecture logicielle dans un langage de modélisation inspiré du modèle C4, puis en tirer des vues interactives, un site statique et des exports PNG, Mermaid, D2 ou draw.io. — un modèle d'architecture dont les vues sont calculées, là où D2 dessine chaque diagramme.

### Compléments

- [[Kroki]] — Serveur HTTP (MIT, Java) à héberger qui donne une seule API pour rendre une vingtaine de langages de diagrammes — PlantUML, Mermaid, D2, GraphViz, BPMN, Excalidraw, DBML, Vega — en SVG ou PNG, par une URL ou une requête POST — mais les langages tournent dans des conteneurs compagnons, et l'instance publique kroki.io reçoit vos sources si on la préfère à la sienne. — rend D2 parmi une vingtaine de langages, sans rien installer chez les clients.
